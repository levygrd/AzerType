# AzerType ⌨️

Application web pour apprendre à taper plus vite au clavier, réalisée dans le cadre d'un projet OpenClassrooms en BTS SIO.

## Présentation

AzerType est un jeu de dactylographie qui propose au joueur de recopier des mots ou des phrases le plus rapidement et précisément possible. Le score est calculé en temps réel et peut être partagé par email.

## Fonctionnalités

- Deux modes de jeu : **Mots** et **Phrases**
- Affichage du score en temps réel
- Validation des mots via un bouton ou la touche Entrée
- Partage du score par email via une popup
- Validation du format de l'adresse email

## Structure du projet

```
Projet AzerType OpenclassRoom/
│
├── index.HTML
├── style/
│   └── style.css
└── script/
    ├── config.js       # Listes de mots/phrases et fonctions utilitaires
    ├── script.js       # Logique principale du jeu
    ├── popup.js        # Gestion de la popup de partage
    └── main.js         # Sélection des éléments HTML et lancement du jeu
```

## Technologies utilisées

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Lancer le projet

Ouvre simplement le fichier `index.HTML` dans ton navigateur, aucune installation nécessaire.
